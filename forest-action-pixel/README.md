# Forest Action Pixel — 森の輪郭

現行版と戦闘を変えずに比較する、ローレゾ3Dの美術試作。

- 現行版： https://tishiyama1.github.io/prototype/forest-action/
- ピクセル版： https://tishiyama1.github.io/prototype/forest-action-pixel/
- 同じ初期状態の比較： `./comparison.html`

`forest-action/` を独立ディレクトリへ複製し、新版の描画・モデルだけを変更しました。現行版、トップページ、他のゲーム、Pages設定は変更していません。three.jsは現行版と同じ0.180.0。HTML/CSS/ES Modulesと固定CDNだけで起動し、ビルド・npm installは不要です。

## 森の美術

連続した地面に、小さな色面からなる土・苔・草・落ち葉のテクスチャを生成します。戦闘領域の楕円境界は内部に残し、見た目は不規則な土の空き地から森へ自然に繋げます。中央は低コントラスト、周縁には根、岩、苔、シダ、倒木を集めています。

木々は根の広がり、枝分かれ、複数の樹冠を持つ広葉樹と段状の針葉樹。巨木・中木・若木を混ぜ、奥と左右に密度を持たせました。カメラ手前の中央には背の高い木を置きません。静かな緑・茶・灰色に暖かい地面の光を添え、遠景フォグと小量の浮遊粒子を重ねます。同種の植生・岩・落ち葉はInstancedMeshでまとめています。

冒険者は青緑の服と短いマント、敵は幅広い肩と茶色の鎧で区別します。姿勢・剣の軌道・座標は現行版と同じです。新たな障害物判定、地形の高さ、環境による攻防補正はありません。

## 描画と比較設定

3Dを低解像度のWebGLRenderTargetへ描き、NearestFilterと整数幅のスクリーンピクセルで拡大します。アンチエイリアスを使わず、最終表示で控えめな色段階とディザを加えます。画面端の最後のピクセルだけ必要に応じてクリップします。DPRを抑えたcanvasをSafariが最終合成する段階も、canvasだけNearest拡大に指定して境界を保ちます。UIはこのレンダーターゲットに含めず、通常解像度のDOMで表示します。画面全体をCSSでぼかす方式は使いません。

画面右上の「調整」→「森の描画」で即時切替できます。

- Low / Medium / High：内部高さの目標144 / 216 / 324px。整数拡大に合わせ、実際の解像度は画面サイズで変わります。
- ピクセル描画ON/OFF：OFFは同じ新版モデル・配置を通常解像度で描画。現行版の美術には戻りません。
- 遠景フォグ、影、風・光・浮遊粒子のON/OFF。
- 「描画設定を戻す」：Medium、各演出ONへ戻します。

| 画面 / 描画DPR | Low | Medium | High |
|---|---|---|---|
| 1280×720 / 1 | 256×144（5px） | 427×240（3px） | 640×360（2px） |
| 844×390 / 1.5 | 317×147（4px） | 422×195（3px） | 633×293（2px） |

括弧は物理ディスプレイ上のピクセル拡大幅。DPRを1.5までに抑え、スマートフォンでの最終画面バッファと影の負荷を制限します。内部解像度とFPSは調整パネルに表示します。影は1024pxの1灯、粒子は32点です。

開始画面の「静止画で描画を比較」は、初期の配置・カメラ・戦闘時計を固定したまま描画設定を試せます。戦闘中も「静止画」で一時停止し、「戦闘へ」で元の戦闘を再開できます。カメラの初期値・計算は現行版と同じです。

## 戦闘コードの保護

次の15モジュールは現行版とバイト単位で同一です：config、game、player、enemy、target、combat、assessment、attack-phase、presentation、camera、input、ui、cards、audio、effects。

表示解像度・フォグ・影・環境設定を変えても、距離・角度・射程・踏み込み・回避無敵・AI・ダメージ・カード評価・勝敗・記録には作用しません。カードの「環境」は引き続き中立で、森の見た目による有利不利を付加しません。

描画の負荷が高い端末では、現行版と同じ時間差の上限処理によりゲーム進行が実時間より遅くなる場合があります。Low、影OFF、環境OFFで比較してください。iPhone実機の60FPS達成は未検証です。
