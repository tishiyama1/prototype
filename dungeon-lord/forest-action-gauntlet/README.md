# Forest Action — 10連戦

比較URL: https://tishiyama1.github.io/prototype/dungeon-lord/forest-action-gauntlet/

既存の Forest Action、前衛版、旅プロトタイプを変更せず、旅用戦闘の描画・後衛追従・身代わり演出を複製した独立エントリーポイント。森林・洞窟の既存背景画像は共有参照、Three.js は既存同様 0.180.0 の CDN を使用する。

## 遊び方

横画面で開始武器と主の強さを選ぶ。初期選択は長剣・標準。フィールドを押すと接近、離すと離脱、押したまま指を動かすとその方向へ移動する。素早く指を弾いて離すフリックで回避し、続けてフリックすれば連続回避できる。右下から通常攻撃・強打を選ぶ。踏み込み斬りは戦利品で習得。PCはW/S接近・離脱、A/D旋回、Shift+移動回避、1/2/3技選択、J攻撃、Space演出短縮。

敵前衛を倒すと後衛が逃走し、3つの戦利品から1つ選ぶ。HP・装備・技・熟練度を引き継ぐ。毎戦HP+12の自動回復もある。第10戦にも3択があり、選択後に完走記録を表示。敗北時は主が身代わりに倒れ、ラン終了。

⚙設定の先頭に検証画面を収納。戦闘番号、敵の立ち回りのヒント、モード、装備、技、熟練度とレアリティ、直近5要素、時間と与ダメージ配分、戦利品履歴を確認できる。JSON保存も可能。モード切替は新規ラン、任意戦闘ジャンプは装備を保持してHP全快。武器・技の検証用貸出は戦闘をやり直す。ジャンプや貸出後の記録には `debug: true` を付ける。

## データと判定

- `js/run-data.js`: 10戦の構成、5種の前衛、3主モード、4武器、技・防具・靴、固定3択報酬、レアリティ閾値。
- `js/run-state.js`: ready → battle → loot → 次戦 / complete、および dead。保存、報酬の一度だけの受領、HP・装備・履歴・熟練度を管理。
- `js/game.js`, `encounter.js`: 既存戦闘への隔離された差分。武器の有効距離・最低距離・発生・構え直し・体勢適性、敵の距離と行動周期、ノックバックを扱う。
- `js/combat.js`, `assessment.js`: 操作依存の間合い・隙・体勢、装備全体（武器、防具、靴）の環境適性、武器・技の性能を評価。攻撃結果の5枚札であり、選択式カードではない。
- `js/run-ui.js`: 開始設定、3択、完走・敗北レポート、設定内の検証画面。通常画面は2本のHP、戦闘番号と武器・モード、敵状態、操作を中心にする。

熟練度は実際に発動した攻撃の使用数を戦闘終了時に加算する（空振りも使用）。各戦武器+4まで、踏み込み斬りも別枠+4まで。12で上質、30で希少。威力が各段階12%増加（技は8%）、上質以上の短剣は構え直しも6%短縮。間合い・敵の隙の条件は変えない。攻撃性能は戦闘内では変わらず、戦利品画面で昇格が分かる。

主の魔法弾は自動発射で、標準と弱体化では敵の構え・攻撃をキャンセルしない。圧倒的だけが王の剣で崩す。モードは物語イベントに接続しない。

保存キーは `forest-action-gauntlet-v1`。勝利後の未選択3択、選択後の次戦、完走・敗北を保存。戦闘中の再読み込みは同戦の開始チェックポイントから再開（弾や演出途中の保存はしない）。既存モードの保存キーとは別。

## 検証

```
node tests/forest-action-gauntlet/logic.mjs
node tests/forest-action-gauntlet/balance.mjs
node tests/forest-action-frontline/logic.mjs
node tests/dungeon-lord-journey/logic.mjs
node tests/forest-action-gauntlet/browser.cjs
```

ブラウザ検証は Playwright/Chromium が必要。専用 GitHub Actions は依存を一時ディレクトリにインストールし、ローカル静的サーバーで実行する。`FOREST_ENV_BASE` 指定で公開URLにも使用可能。詳しい結果と制約は `VALIDATION.md`。

## 範囲と制約

ワールドマップ・生活管理・能力譲渡・物語分岐は追加しない。大規模収集やランダム生成はない。武器と敵のドット絵は既存アトラス描画を拡張した簡易シルエット。森林・洞窟の背景は既存画風を保持。

戦闘時間と援護比率は立ち回りと武器で変わる。理想入力の自動プレイだけでは面白さを証明できない。短剣＋弱体化は他武器より長く、一部の戦闘は60秒を超える。実機iPhone Safariでのタッチ・音・GPU・安全領域は未確認。通信のない初回起動やCDN障害時は遊べない。

操作改修: フリックは直近120msの移動速度と離した瞬間で判別。ゆっくりしたドラッグは通常移動。回避中は次の1回を0.30秒だけ先行受付し、各回避の後半は無敵ではない。後衛は両前衛・相手後衛から離れた目標へ最高2.2で緩く加減速。高速移動する前衛と一時的に近くなっても瞬間移動で解消しない。致命傷時は主の進入→身代わり→倒れる場面を0.25倍速、約4.4秒で表示する。
