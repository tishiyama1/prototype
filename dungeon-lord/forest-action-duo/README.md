# Forest Action — 2対2固定戦闘

ビルド不要の比較試作。既存1対1版をコピーし、このディレクトリ内だけを変更しています。Three.js 0.180.0、ES Modules、既存GitHub Pagesを使用。

- 森: https://tishiyama1.github.io/prototype/dungeon-lord/forest-action-duo/?scene=forest
- 洞窟: https://tishiyama1.github.io/prototype/dungeon-lord/forest-action-duo/?scene=cave
- 改修元の1対1版: https://tishiyama1.github.io/prototype/dungeon-lord/forest-action-card-impact/

## 操作

人間だけを直接操作します。W/Sで接近・離脱、A/Dで選択中の敵を中心に回り込み。スマートフォンは左スティック。フィールド上のスワイプ、PCのShift＋WASDで回避。1/2/3で斬撃・突き・強打、Jまたは右の攻撃ボタンでカード攻防を指示。

敵A/Bは上部HPボタン、敵の頭上ラベル、PCのTabで切り替えます。金色の足元リングとボタン枠が選択対象。回避中の切替は回避終了後に適用し、途中で移動の基準が変わることを防ぎます。カード中は対象固定、4体の通常時間・AI・弾を停止します。Space/カード上タップで演出短縮。技の性能・4項目の判定・既存の攻防演出時間は変更していません。

## 4体の役割

| キャラクター | HP | 役割 |
|---|---:|---|
| 冒険者 | 100 | ターゲット相対移動とカード攻撃を手動で行う |
| ダンジョンの主 | 100 | 人間から離れすぎると追従。近い敵へ接近し、12ダメージの爪攻撃。攻撃準備・攻撃を止めると0.7秒の体勢崩れ。正面の防御には受け止められる |
| 敵A・牙の前衛 | 120 | 既存の警戒・防御・接近・斬撃・突進・大振り・硬直・回り込みを使用 |
| 敵B・呪術の後衛 | 75 | 距離4.6〜6を目安に離脱・旋回。0.95秒の予備動作後、狙いを固定した8ダメージの呪弾。至近距離では12ダメージの杖攻撃 |

敵は距離・現在の標的・直近の被弾相手から人間か主を選びます。攻撃準備から攻撃までは標的を保持。プレイヤーの攻撃入力に反応して即時に回避するAIはありません。主は、近い範囲なら人間が選んでいない敵にも向かう傾向を持ちます。追従だけでなく、交戦・足止めを行います。

生存者だけに軽い押し分けを適用し、楕円境界内に制限。敵全滅で勝利、味方全滅で敗北。人間だけが倒れた場合は主の戦いを観戦します。リトライで4体のHP、AI、標的、弾、カード、戦績を初期化。

各頭上にHP・行動・攻撃対象を簡潔に表示。主の貢献（命中・ダメージ・足止め）をリザルトに表示。調整パネルでは4体のHP/行動/標的と弾数を確認できます。

## ビジュアル

参考画像の紫の体、金の冠、赤い四角の目を、既存と同じ64×48セル・4方向・6フレームの整数ピクセルで描画。ダンジョンの主は剣鬼と異なる幅広いシルエット、敵Bは青灰色のローブと杖。各描画インスタンスにID・アーキタイプを持たせ、戦闘データから分離しています。

背景は既存の森・洞窟の2Dレイヤーを読み取り専用で利用。影、視差、OFF/NORMAL/OVER環境演出とカード成功時の全画面ピクセル攻撃演出を維持。4体に対して前景の遮蔽を調整し、カメラは生存者全体を収めます。

## 実装構造

- `duel-base.js` — 元の1対1カード進行。コピー元と同一
- `game.js` — 4体・個別HP・勝敗・弾・カード対象・時刻の統合
- `team-target.js` / `team-space.js` — 標的管理・押し分け・弾の数値衝突
- `companion.js` / `support.js` — 主と後衛の自律行動。前衛は既存`enemy.js`
- `sprite-art.js` / `character.js` — 4方向のピクセル描画と接地影
- `duo-effects.js` — 2体の予兆・呪弾と既存ピクセル効果の接続
- `combat.js` / `assessment.js` / `config.js` / `player.js` / `input.js` — 元版と同一

## 検証

`node tests/forest-action-duo/logic.mjs`（Node.js 24）。npm install不要。既存ファイル保護、両対象で126条件の既存判定・評価の一致、カード中の全体停止、スキップ・OFF、ターゲット固定と自動切替、回避中の予約、境界での押し分け、主の攻撃と足止め、後衛弾、全滅条件、リトライ、同入力の再現を検証します。

ブラウザ試験はPlaywright＋Chromiumで行います。スマートフォン画面とタッチのエミュレーションはiPhone Safari実機試験とは別です。実機でのFPS・手触り・熱負荷は未確認です。

## 試作として残る課題

- 回復・身代わり・連携カードは実装していません。
- 人間死亡後の待ち時間が長くなる場合があります。最終バランスは未確定。
- 密集時にはラベルとスプライトが近づきます。頭上だけに頼らず上部A/Bボタンでも選択可能です。
- 単純な押し分けであり、複雑な経路探索や障害物衝突はありません。
- 主の攻撃は爪、後衛は直進弾の最小実装です。4体の読みやすさ・相棒の存在感を評価するためのものです。
