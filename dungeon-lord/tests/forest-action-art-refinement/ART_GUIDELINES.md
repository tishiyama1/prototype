# Forest Action 背景アートガイドライン v1.0
作成日：2026-10-12
基準：公開中の擬似3D森シーン（forest-action-layered）
比較対象：擬似3D洞窟シーン（forest-action-cave）

## 1. 共通方針
**背景は、雰囲気を伝えながら、キャラクターの行動を読むための余白を残す。**

採用するのは「大きな形と穏やかな陰影で整理した、スタイライズドなファンタジー背景」。森の中央の地面が基準です。あっさりした表現は、造形の粗さや品質の低さを意味しません。素材の細かな説明を減らし、構図・シルエット・まとまった色面で場所を伝えます。

通常戦闘では、人物と武器・敵の予備動作が先に読み取れ、その後に場所の雰囲気が伝わる構成にします。攻撃フェーズでは既存のカードUIが主役です。背景の追加光や粒子が、カード評価や技の軌跡に見えないようにします。

以下の数値は新規制作を揃えるための**初期目安**です。既存画像の測定値、業界標準、性能保証ではありません。数値を守ってもキャラクターが読みにくければ不合格です。最終表示での読みやすさを優先します。

## 2. 情報量・描き込み密度
### 共通ルール
- 戦闘に使う地面の約70%を、大きな色面と緩い色の変化で構成する目安とします。静かな面にも土・苔・湿りなどの素材感は残します。
- 「静かな面」とは、細い線、小石、葉、亀裂、強い陰影が連続せず、人物の輪郭・武器・影を邪魔しない場所です。単色の床を要求するものではありません。
- 場所を代表するランドマークは1〜2か所。石碑、崩れた壁、ランタン、入口などを周縁へ配置します。これは個々の石や葉の個数制限ではありません。
- 細部は周縁の小さなまとまりへ集めます。戦闘地面へ均等にばらまかないようにします。
- 人物の移動範囲全体を確認します。初期位置だけが読みやすい背景では不十分です。
- 将来4体を配置できるよう、中央の空間を広く保ちます。今回の戦闘人数や当たり判定を変更する指示ではありません。

### やるべきこと
土のまとまり、草の縁、岩の塊、葉の堆積など、まず大きな面で整理します。その後、場面を説明する最低限の細部を加えます。

### やってはいけないこと
全面に亀裂・石畳・葉脈・苔の粒・小石を描くこと。中央の床を、細かな模様の展示場所にすること。描き込み量だけで品質を上げようとすること。

## 3. 形状・シルエット
- 輪郭は読みやすく、わずかに不規則にします。均一な幾何学形状にも、全周がギザギザの形にも寄せません。
- 木：幹の曲がりと主要な枝、まとまった樹冠で形を伝えます。樹皮の溝や葉1枚ずつの描写を増やさないようにします。
- 岩：少数の大きな面と欠けで形を伝えます。細かな多面体や網目状の亀裂を重ねません。
- 遺構：全体の輪郭と1〜2か所の崩れ方で古さを示します。装飾、文字、欠損、苔をすべて細密に説明しません。
- 背景は太い黒輪郭で囲いません。近い物は輪郭を読めるようにし、遠い物は輪郭と細部の明暗差を弱めます。
- 地面の細部より、主要物の輪郭を少し明確にします。人物には既存のドット絵の輪郭・配色を残します。

**禁止：** 球体と棒だけに戻すこと、全ての岩面を鋭いハイライトで区切ること、背景の輪郭をキャラクター以上に強くすること。

## 4. 陰影とコントラスト
- 物の立体感は、基本色・大きな影・控えめな明るい面の2〜3段階を出発点にします。最終画像の色数を2〜3色へ制限する意味ではありません。
- 主光源の方向を場面内で揃えます。影は大きなまとまりを優先し、微細な陰影を増やしません。
- 戦闘地面には、強い明暗のまだら模様や真っ黒な帯を横切らせません。
- 洞窟は、周縁と通路の奥を暗くし、人物が立つ床には読める中間調を残します。「全体を暗くする」方法で洞窟らしさを作りません。
- ランタンなどの強い明部は小さくします。大きな白飛び、広い発光、周囲すべての岩面への強い反射を避けます。
- 遠景はコントラストを弱めます。必ず明るくする必要はありません。洞窟の奥は暗いままでも、細かな白い縁や強い面分割を減らすことで整理できます。
- 背景のエッジを柔らかく整理することと、画面全体をぼかす処理を混同しません。

**禁止：** 全面の深い黒、硬い影の連続、強い逆光、人物と同じ場所で目立つ光の柱、カード表示中に目立つ環境フラッシュ。

## 5. 色と彩度
- 背景は低〜中彩度を中心に構成します。色の明度差で形を伝え、素材ごとに強い色を足さないようにします。
- 制作用の基本色をHSVで決める場合、主な色は彩度20〜45%、小さなアクセントは40〜65%を初期目安とします。描画後の全ピクセルをこの範囲に収めるルールではありません。
- パレットは「主色系・補助色系・影色系・アクセント色系」の4役で整理します。最終画像の使用色数を4色に制限する意味ではありません。
- シーンごとに色相や平均的な明るさは変えて構いません。揃えるのは、彩度の抑え方・影の強さ・アクセントの小ささです。
- 土、木、岩、苔の色を別々に目立たせず、同じ空間の色として近づけます。
- プレイヤーの青系、敵の緑系と背景が重なる場合は、その背後の面の色や明度差を調整します。背景に合わせてキャラクターの性能や描画サイズを変えません。
- 強いアクセントは周縁へ限定します。洞窟の橙色、墓地の淡い青などが画面全体を支配しないようにします。

## 6. 地面・戦闘エリア
- 中央の床は広く、静かに、連続して見えるようにします。奥行きのある通路や古道も、戦える面を狭い一本道へ見せないようにします。
- 足場は大きな土・苔・石の面で整理し、小石や落ち葉は道の端へまとめます。
- 地面と周辺物の間には、薄い苔、土、根、接地影などを挟みます。すべての境界を濃い線や岩の輪で囲いません。
- 人物の足元には、座標に追従する小さな接地影を残します。既存の投影影と光源方向も矛盾しないようにします。
- 写り込みや濡れ表現を使う場合も、人物の足元を強い反射で埋めません。
- 戦闘範囲、地面の高さ、初期位置、当たり判定は変えません。絵の段差・壁・装飾が、実際に通れない場所だと誤解されないようにします。
- 周辺物で楕円境界を自然に隠しますが、床の読みやすさを優先します。境界を隠すために、人物の移動範囲を巨大な岩や草で覆いません。

## 7. 前景・中景・遠景
標準構成は4役です。素材枚数は必ず4枚に固定する必要はありません。役割と再利用しやすい管理を優先します。

| 役割 | 内容と扱い |
| --- | --- |
| 遠景 | 場所の奥行き・空気・奥へ続く景観。細部とコントラストを最も弱くする。 |
| 中景 | 樹木、岩壁、石碑、倒木、遺構など。中央に戦闘用の開けた空間を残す。 |
| 地面 | 人物の接地と移動を支える連続した床。穏やかな素材感を持たせる。 |
| 前景 | 端の木・枝・草・岩で画面を縁取る。中央を覆わず、重なった場合は透過などで人物の行動を読めるようにする。 |

### 投影と接続
- 基準は現行の正射影カメラ、初期俯角43°・設定ズーム1.23です。表示サイズや両者の距離による既存カメラの調整は維持します。
- 同じカメラ・人物サイズ・初期配置で素材を確認します。シーンごとの画像に強い消失点を描いて、同じカメラなのに別の視点へ見える状態を避けます。
- 地面と立物の接続、透明な抜け、前景の余白を、素材生成前に決めます。
- 視差は微量です。共通のカメラ移動とは別に足すずれは、通常追従の範囲で画面幅の約1%以内を初期目安にします。最終的には継ぎ目や浮遊感が出ない量に調整します。
- 固い岩・支柱・石碑は揺らしません。葉や光など、動いてよい要素だけを独立させます。
- 画像と配置・視差・光の定義は分離し、場面固有の変更が戦闘ルールへ入らない構成にします。

**禁止：** 遠景にも前景と同じ密度・強い輪郭を付けること。前景で中央を覆うこと。強い視差で板の分離や継ぎ目を見せること。画像の見た目に合わせて移動・戦闘判定を変えること。

## 8. 環境演出
- 1シーンは、ゆっくりした動き1系統と、少量の付随要素1系統を基本とします。例：葉の揺れ＋少量の落ち葉、ランタン光の揺らぎ＋少量の粉塵。
- 追加の発光は明るさの変化を基準値の±5〜10%程度から始めます。目立つ明滅にせず、暗転・白いフラッシュを避けます。この値は追加効果の初期設定目安です。
- 粒子は同時表示10点前後から確認します。数だけでなく、画面上の大きさ・明度・配置を抑えます。大きな10粒は「少量」とは扱いません。
- 人物や技の軌道の周辺で、強い粒子・火花・揺れを出さないようにします。
- 動きが目立たないと場所が伝わらないなら、先に静止した構図を直します。
- 環境演出OFFでも、背景として成立することを合格条件にします。
- 攻撃カード中は既存の暗幕を優先します。カードの外側で環境の光が主張しないようにします。

## 9. シーン制作の手順とチェック項目
### 制作手順
1. 基準の森と同じカメラ・人物配置で、地面と主要物の大きな形だけを配置する。
2. グレースケール表示・縮小表示で、人物と武器が先に読めるか確認する。
3. 色・陰影・接地を整える。周縁だけへ必要な細部を加える。
4. 4役へ分離し、視差・透明な抜け・前景の重なりを確認する。
5. 最後に環境演出を少量追加する。
6. 同じ人物と同じ画面サイズで森の基準画像と並べ、過剰な部分を削る。

### 合格チェック
- [ ] 森の基準画像と並べて、素材の描き込み密度と陰影の強さが大きく離れていない。
- [ ] 人物・武器・敵の予備動作が、背景の亀裂や影より先に読み取れる。
- [ ] 戦闘地面に十分な静かな面があり、小石・葉・模様が全面に散っていない。
- [ ] 場所の特徴が、1〜2か所のランドマークと大きな形で伝わる。
- [ ] 明るい場所、暗い場所、画面端、人物が重なる位置でも状態を読める。
- [ ] キャラクターや武器が背景と同化していない。
- [ ] 光源方向、背景の影、人物の影に大きな矛盾がない。
- [ ] 地面と岩・木・人工物の接続に、浮きや濃すぎる縁取りがない。
- [ ] 前景が重なっても、人物の頭・武器・予備動作を隠し続けない。
- [ ] パララックスで継ぎ目、透明な穴、板の浮遊感が出ない。
- [ ] 環境演出OFFでも景観が成立し、ONでも動きが戦闘の注意を奪わない。
- [ ] カード表示中に背景や追加光が主役にならない。
- [ ] 1280×720、844×390、667×375で、背景・人物・UIの関係を確認した。
- [ ] 画面幅を約半分に縮小しても、敵の構えと武器が読める。これは実際にゲームを低解像度化する設定ではなく、素材の読みやすさの点検。
- [ ] 将来4体を置ける中央の余白がある。現行戦闘を2対2へ改造することは不要。
- [ ] 背景変更で座標、移動、攻防判定、カード評価、HP、勝敗・リトライが変わっていない。
- [ ] iPhone Safari実機の確認状況と、ブラウザの画面サイズ・タッチ相当確認を区別して記録した。

これらは今後の制作に対するチェックです。ガイドライン作成の時点で、新しい素材の実装・実機確認が済んだことを意味しません。

## 10. シーン別に変えるもの・揃えるもの
| シーン | 場所の特徴として残すもの | 情報量を抑える方法 |
| --- | --- | --- |
| 森 | 緑、土の古道、樹冠、石碑、柔らかい木漏れ日 | 中央の地面を静かにし、葉や根は周縁にまとめる。細かな樹皮・葉脈を描き込まない。 |
| 洞窟 | 青灰色の岩、暗い奥、古い支柱、小さな暖色光 | 岩を大きな面でまとめ、亀裂・小石・石畳の線を減らす。床は読める中間調にする。 |
| 遺跡 | 灰〜砂色、崩れた壁・柱、苔、年代を感じる形 | 見せる崩れを選び、全ての石材にヒビや彫刻を入れない。中央の石床は広い面で整理する。 |
| 墓地 | 灰緑〜灰青、少数の墓標、土と低草、静かな空気 | 墓標は周縁のまとまりへ。文字、骸骨、濃い霧、強い青い光を重ねて場所を説明しない。 |

**揃えるもの：** 投影、人物の見え方、中央の余白、輪郭の強弱、陰影の段階、彩度の抑え方、アクセントの面積、細部の置き方、環境演出の控えめさ。

**変えてよいもの：** 色相、場面の平均的な明るさ、素材、大きなシルエット、ランドマーク、光の温冷、静かな環境演出の種類。

同じ色、同じ明るさ、同じオブジェクトを全シーンへ使い回す必要はありません。「情報の整理の仕方」を共通化します。

## 11. 森と洞窟の現状差分
以下は保存された実ゲーム画面を並べた視覚的な比較です。密度・色・コントラストの数値測定ではありません。

| 観点 | 森 | 洞窟 |
| --- | --- | --- |
| 地面 | 広い土の色面。小石・細部が少ない | 石畳、割れ目、小石、細かな明暗が床全体に続く |
| 形 | 樹木・岩・遺構を大きな塊として読める | 岩の面分割と欠けの描写が細かい |
| 陰影 | 大きな木陰と穏やかな中間調 | 深い暗部とランタン周辺の強い明部が対比する |
| 主な視線誘導 | 開けた地面と人物 | 大きいランタンと奥の通路にも強く引かれる |
| 遠近の印象 | 広い床を見渡す俯瞰構図 | 描かれた通路の収束が強く、奥行きが主張する |
| 人物との関係 | 人物の輪郭が静かな床で読みやすい | 人物は見えるが、背後の模様と明暗が競合しやすい |

両者の実カメラ初期設定は俯角43°・設定ズーム1.23で共通です。遠近の差は主に背景画像の描き方・構図にあります。

## 12. 揃えるための改修提案
### 優先1：洞窟の戦闘地面
亀裂、石畳の輪郭、小石の個別描写を減らし、広い土・岩盤の色面へまとめます。場所の特徴は床の端と数か所の石で伝えます。描き込み量を森に近づける最初の対象です。

### 優先2：洞窟の岩と陰影
細かな面分割と鋭い縁を減らし、大きな面と緩い明暗へ置き換えます。暗い奥は残し、戦闘地面に深い黒や強いまだら影を増やさないようにします。

### 優先3：ランタンと通路
暖色光は残します。ランタンの金具・細部・強い発光を抑え、人物より先に目へ入る面積と明暗差を下げます。通路の遠近を少し弱め、広い床を見渡す構図とのつながりを整えます。

### 優先4：森の維持と微調整
森は基準として維持します。洞窟へ合わせるために描き込みを増やしません。人物が移動する先に濃い木陰が重なる部分や、画面端の密度だけを必要に応じて整理します。

**対応の優先順位は、地面の整理 → 大きな形と陰影 → 光の主張 → 周縁の細部です。**
全面のぼかし・一括の彩度低下だけでは、情報量や構図の差は解消しません。素材自体の整理が必要です。

本依頼ではガイドラインの作成までとし、ゲーム背景や公開版の変更は行っていません。

## 13. 重要ルールの要約
1. 中央は静かに、細部は周縁へ。
2. 小さな模様より、大きな形と色面で場所を伝える。
3. 背景の陰影・輪郭・光が人物より目立たないようにする。
4. 暗いシーンにも、戦う床の読みやすさを残す。
5. 色相は変えてよい。描き込み密度と明暗・彩度の扱いを揃える。
6. 前景と視差は控えめにし、人物の行動を隠さない。
7. 環境演出OFFでも成立する背景を作る。
8. 洞窟を森の密度へ寄せる。森を洞窟の細密さへ寄せない。
