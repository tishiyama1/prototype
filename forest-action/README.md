# Forest Action — 間合いを読む

公開： https://tishiyama1.github.io/prototype/forest-action/

『ダンジョンの主』に向けた戦術アクション試作。楕円形の森で1対1の戦闘を繰り返します。移動・回避と敵の攻撃はリアルタイム、プレイヤーの攻撃は指示時点の状態から決定する攻防シミュレーションです。旧版の横スクロール・2レーン・コンボ入力は廃止しました。

## 操作

| 操作 | PC | iPhone横画面 |
|---|---|---|
| 接近 / 離脱 | W / S（上下矢印も可） | スティック上 / 下 |
| 左 / 右へ回り込む | A / D（左右矢印も可） | スティック左 / 右 |
| 高速移動・回避 | Shift＋移動キー | 森のフィールドをスワイプ |
| 技を選ぶ | 1：斬撃、2：突き、3：強打 | 右下の3つの技ボタン |
| 攻撃を指示する | J | 丸い攻撃ボタンを1回タップ |
| 一時停止 | Escape / Ⅱ | Ⅱ |

左右入力はターゲットを中心に円弧で移動します。視点が動いても操作の意味は変わりません。斜め入力と複数指に対応します。スワイプはフィールドから始めた28px以上・650ms未満のジェスチャーで、スティック・ボタン・調整パネルからの操作は対象外です。指を離す、キャンセルする、画面外へ出る、一時停止する場合に入力を解除します。縦画面では案内を表示して進行を止めます。

## 3つの技

| 技 | 威力 | 発生 | 最適間合い | 最大踏み込み | 構え直し |
|---|---:|---:|---:|---:|---:|
| 斬撃 | 10 | 0.20秒 | 1.5 | 1.2 | 0.40秒 |
| 突き | 15 | 0.35秒 | 2.2 | 2.5 | 0.55秒 |
| 強打 | 30 | 0.60秒 | 1.3 | 0.5 | 0.70秒 |

構え直し中も移動・回避できます。連打やコンボは不要です。表示する射程は最適間合い＋最大踏み込みの目安で、敵の移動、境界、姿勢によって結果は変わります。

- 接近する敵には素早い斬撃。遠い突進を迎えるには突き。
- 正面の防御は軽い攻撃を止めます。近距離の強打で、発生時まで続く防御を崩せます。
- 突きは発生中の横移動量が大きいと回避されます。
- 硬直が発生時間より長く残っていれば、強打を当てられます。
- 敵の攻撃到達が先なら攻撃を潰されます。射程外の指示は空振りです。

全判定は距離・相対角度・速度・行動の残り時間と技から決定します。乱数は使いません。技の発生までの予測は現在の行動とその残り時間に限定した簡潔なモデルです。敵は攻撃入力を見てAIを切り替えません。確定結果を回避・防御・反撃などの演出で表現します。

## 時間と描画

`combat.js` の `capture()` が状態・技・調整条件をコピーし、純粋関数 `resolve()` が命中 / 回避 / 防御 / 空振り / 攻撃中断 / 迎撃を確定します。`game.js` が通常更新を停止し、独立した演出時間だけを更新します。`presentation.js` は描画用の姿勢・位置を生成し、実ゲーム状態には触れません。演出終了時、HP・位置・敵状態・結果集計を一度だけ反映します。

通常の敵AI・移動・無敵・クールダウン・戦闘時計は演出中に止まります。カメラは寄り・構え・踏み込み・結果・復帰を短く演出します。斬撃・突き・強打でモーションと視点を変え、命中・迎撃だけに短いヒットストップと揺れを加えます。演出OFFでは同じ結果を即時反映します。途中でOFFにしても二重反映しません。

通常更新と演出更新は `requestAnimationFrame` による1/120秒の固定ステップです。復帰時の時間差はリセットし、タブ非表示・フォーカス喪失・縦画面では演出も止めます。戦闘時間と命中率の定義はリザルトにも表示します。戦闘時間は演出・一時停止を除き、命中率は命中＋迎撃成功の割合です。

## 調整

右上の「調整」で移動、回り込み、回避、技ごとの威力・発生・間合い・踏み込み、正面角度、突きの横許容幅、強打の防御崩し距離、迎撃猶予、カメラ、演出速度を変更できます。判定値の変更は次の指示から適用します。敵状態、残り行動時間、距離、角度、FPS、直近の判定理由を表示します。初期設定へ戻せます。

## 構成・公開

ビルド不要のHTML/CSS/ES Modules。three.jsはimport mapで `0.180.0` に固定してjsDelivrから読み込みます。外部モデル・物理エンジン・npm・サーバーは不要です。CDNへの接続が必要です。

- `target.js`：ターゲット管理、相対移動、楕円境界
- `player.js` / `enemy.js`：リアルタイムのキャラクター状態
- `combat.js`：状態取得・予測・確定判定
- `game.js`：戦闘進行、時計、結果反映、再戦
- `presentation.js` / `character.js` / `camera.js` / `effects.js`：独立した描画と演出
- `forest.js`：森、ライティング、軽い風の表現
- `input.js` / `audio.js` / `ui.js` / `main.js`：ブラウザ固有処理
- `config.js`：初期値と調整パラメータ

既存リポジトリ `tishiyama1/prototype` の `main` / ルートからGitHub Pagesで配信します。公開方式を変えず `/prototype/forest-action/` を維持し、他の単一HTML試作品は変更しません。

## 検証

```sh
node tests/forest-action/run.mjs
node tests/forest-action/playthrough.mjs
```

判定・状態停止・再開・スキップ一致・撃破・再戦・相対移動などを自動確認します。playthroughはHPやAIを書き換えず、通常入力だけで敵を倒す観察方針の試戦闘です。詳しくは [VALIDATION.md](VALIDATION.md) を参照してください。

任意のブラウザ自動検証は、PlaywrightとChromiumが導入済みの検証環境で `node tests/forest-action/browser.cjs` を実行します。ゲーム本体のビルド・npmインストールは不要です。`FOREST_QA_URL` で公開URL、`FOREST_QA_BROWSER` でブラウザ実行ファイル、`FOREST_QA_ARGS` で起動引数のJSON配列、`FOREST_QA_OUTPUT` で記録先を指定できます。未指定時は同じプロセスのHTTPサーバーからローカル検証します。
