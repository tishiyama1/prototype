# Forest Action — 森の向こうへ

『ダンジョンの主』に向けた、2.5D・2レーン横スクロールアクションの操作感試作。

公開パス: `https://tishiyama1.github.io/prototype/forest-action/`

HTML / CSS / ES Modules。three.js **0.180.0** を jsDelivr の import map で読み込みます。ビルド・npm install・サーバーAPIは不要です。ES Modules のため、開発時は file:// ではなく静的HTTPサーバーで開いてください。

## 操作

| 操作 | PC | タッチ |
|---|---|---|
| 左右移動 | A / D、左右矢印 | 左下の左右を長押し |
| 奥 / 手前へ | W / S | 左下の奥 / 手前 |
| 剣の攻撃 | Jをタイミングよく繰り返す | 斬るを繰り返しタップ |
| 左右回避 | K | 回避 |
| 一時停止 | Escape、上部のⅡ | 上部のⅡ |

iPhoneは横画面を想定。縦画面・フォーカス喪失・バックグラウンド移行時には進行を停止し、復帰後に「続ける」で再開します。

## 判定規則

- FRONT（手前） / BACK（奥）の2レーン。Y方向の移動とジャンプはありません。
- レーン切替開始時に移動先を確定します。切替中も横移動できます。所属レーンは**切替完了時**に変更します。
- 切替中も元レーンで被弾します。新しい通常攻撃は開始できません。被弾した場合は元レーンへ戻り、切替を中断します。
- レーン入力は押した瞬間に1回だけ受け付けます。押しっぱなし・キーリピートで往復しません。
- 回避は方向入力優先、無入力なら向いている方向へ。レーンを維持し、開始直後0.19秒間は無敵。0.22秒移動、0.08秒硬直、再使用待ち0.64秒。攻撃から回避にキャンセルできます。
- 通常攻撃は最大3連撃。入力バッファは0.22秒。攻撃中は通常の18%の移動速度で位置を調整できます。各振りは同じ敵に1回だけ命中します。
- 通常攻撃は同じレーン・向いている方向・X距離で判定します。倒れた敵には命中しません。
- ゴブリンの赤い予告は範囲を示します。突進の予告は0.85秒、方向とレーンは開始時に固定します。突進後の硬直は0.8秒。
- ヒットストップは全キャラクター・敵AI・無敵・クールダウンのシミュレーションを同時停止します。入力は停止中も保持し、復帰後に処理します。

## ステージ・記録

短い森を右へ進み、7体のゴブリンを倒して石の門へ到達するとクリアです。敵が残っている間はゴールできません。死亡・クリアからすぐリトライできます。

スコア = `撃破数 × 1000 + max(0,150 − 経過秒) × 30 − 被ダメージ × 35` を四捨五入し、最低0とします。時間はゲームが動いている間の時間で、ヒットストップを含み、一時停止・非アクティブ時間を除きます。

クリア時のベストタイムとベストスコアを `forest-action:best:v1` のlocalStorageへ保存します。既存作品の保存キーは使用しません。保存できない環境でもプレイできます。

## 調整

右上の「調整」でFPS、HP、所属レーン、アクション状態、当たり判定を確認できます。

移動速度、加速度、減速度、攻撃速度、攻撃範囲、ヒットストップ、回避距離、回避無敵時間、レーン切替時間、レーン間距離、カメラ俯角、ズーム、追従速度、画面内の左右位置を変更できます。調整値はセッション中だけ保持し、初期設定へ戻せます。開始済みの攻撃・回避・切替は開始時の時間設定を使い、次回から新しい設定を使います。

## 構造

- `config.js` — パラメータと定数
- `game.js`, `player.js`, `enemy.js`, `combat.js` — DOM / three.jsに依存しないゲームロジック
- `input.js`, `audio.js`, `ui.js` — ブラウザ固有処理
- `main.js` — 1/120秒の固定ステップ、描画、ライフサイクル
- `character.js`, `forest.js`, `effects.js`, `camera.js` — ローポリモデル、森、演出、カメラ

描画はrequestAnimationFrame。フレーム差分を50msに制限し、非アクティブからの復帰で時間が飛ばないようにしています。植物はInstancedMesh、画素比は最大1.5、シャドウは1024pxです。重い物理エンジン、ポストプロセス、外部モデルは使っていません。

## 検証

リポジトリのルートから `node tests/forest-action/run.mjs` と `node tests/forest-action/playthrough.mjs`。テストにもnpm installは不要です。

ブラウザ検証の記録は `VALIDATION.md` を参照してください。iPhone Safari実機でのフレームレート・発熱・音声復帰は別途確認が必要です。
