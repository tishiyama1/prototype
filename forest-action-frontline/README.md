# Forest Action — 前衛決闘と後衛自動援護

`forest-action-growth/` の3段階2対2版を保護して複製した独立比較版。公開パスは `forest-action-frontline/`。森／洞窟、通常／高速／詳細カード、環境演出・画面全体の攻撃演出、PC／タッチ操作を維持。

## 構造と操作

主人公と敵前衛だけが楕円の戦闘領域を移動。敵前衛が唯一の攻撃対象。ターゲット切替のボタン・頭上タップ・Tab切替は廃止。

- WASD／スティック：敵前衛に接近・離脱・回り込む。
- Shift+WASD／フィールドスワイプ：回避。
- 1/2/3または右下3ボタン：技。J／攻撃ボタン：戦況から攻防を確定。
- 上部の序盤／中盤／終盤は戦闘をリセットして切替。URL `stage=early|middle|late`。
- 主は左奥 `(-8,-4.6)`、敵後衛は右奥 `(8,-4.6)` の定位置。両者は前衛の衝突・近距離戦闘に参加しない。
- 敵前衛HP0で敵後衛が0.90秒の逃走。敵後衛HPを削る必要はない。

## 3段階

| | 序盤 | 中盤 | 終盤 |
| --- | ---: | ---: | ---: |
| 主人公HP | 70 | 100 | 145 |
| 斬撃／突き／強打 | 7 / 10 / 20 | 10 / 15 / 30 | 15 / 23 / 45 |
| 主の表示倍率 | 2 | 1 | 0.62 |
| 主の技 | 王の剣 | 魔法弾 | 弱い魔法弾 |
| 主の威力 | 48 | 13 | 2 |

主のHPは旧比較版の520／145／38を保持するが、身代わりの生死判定には使わない。どの段階でも致命傷に対する身代わりは死亡・敗北となる。敵前衛HP120・敵AI・攻撃威力、敵後衛の予兆・周期・弾威力8は全段階で共通。

## 後衛

主の固定位置・射撃タイマーは3段階共通。初期待機0.65秒、構え0.55秒、攻撃0.18秒、硬直1.40秒、待機0.20秒。追従・接近・殴打なし。

王の剣は宣言時の敵前衛の座標へ5本を生成し、0.52秒で叩き込む。半径2.8以内の敵前衛が対象。物体生成能力であり、術者から発射する魔法ではない。中盤以降は主の位置から魔法弾を速度7.5／寿命2秒で直進発射する。正面防御は魔法弾を止められる。

敵後衛は初期待機3.5秒後、次を交互に行う。

1. 射撃：1.10秒の予兆開始時に主人公の座標へ照準を固定。地面の細い紫色の線で予告。威力8、速度5.6、寿命4.2秒の直進弾。追尾しない。主人公だけに判定。
2. 警戒支援：0.60秒の動作後、敵前衛が待機・防御中ならその状態を0.35秒延長。硬直・被弾・体勢崩れ・攻撃準備・攻撃を変更しない。回復や追加状態異常はない。

各行動後は硬直1.6秒＋待機2.4秒。カード中は両後衛のタイマーとすべての飛翔物を凍結。射撃でカードを中断しない。前衛死亡時にすべての弾・剣を消去し、追加ダメージを防ぐ。

## 身代わり敗北

主人公への致命傷を、リアルタイム近接・後衛弾・カード反撃の共通入口で検知。主人公HPを減らさず、主が確実に前へ到着。

- 序盤：転移光と即時出現。
- 中盤・終盤：距離や能力に依存しない0.10秒の疾駆補間。
- 0.18秒で主が死亡。0.85秒で敗北画面。
- 10倍ダメージ・生存判定・反撃・吹き飛ばしなし。
- 通常シミュレーションは専用演出中に停止。主人公は生存したまま。

## 位置取りと戦闘テンポ

`combat.js`／`assessment.js`／前衛AI／移動計算は元の3段階版と同一。判定は4項目のまま。画面に現在の間合いと正面／側面を表示。

この比較版では、防がれた攻撃に0.48秒、空振りに0.18秒の追加構え直しを設けた。判断なしの攻撃指示を少し不利にし、有利な間合い・隙を捉えた命中では従来の構え直しを維持。判定結果・威力・カード評価そのものは変更しない。

## 検証シナリオ

「調整」→専用動作検証。毎回HP・位置を設定して戦闘をリセットし、画面に「検証用戦闘」と表示。

- 身代わり敗北
- 前衛撃破→後衛逃走
- 後衛射撃の予兆
- 選択段階の王の剣／魔法弾

通常のリトライは検証フラグ、身代わり・逃走・HP・弾・統計を初期化。

## 検証と課題

`node tests/forest-action-frontline/logic.mjs`：13群、189攻防条件。`balance.mjs`：3段階×4固定操作の12試行。ブラウザ検証は別記録。

序盤は無操作で主が勝つ。中盤は無操作でも長く耐えれば勝てるため、主人公の参加を必須にはできていない。終盤は人間がほぼ全火力を担当する。観察・旋回・技選択の固定操作は、同じ技を指示し続ける操作より無被弾・短時間になったが、斬撃の連続指示でも勝てるケースが残る。難易度・敵の隙の調整は引き続き課題。

iPhone実機Safari、実機FPS／発熱、主観的な見やすさ・楽しさは未検証。
