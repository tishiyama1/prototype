# Forest Action — 前衛決闘と後衛追従援護

`forest-action-frontline/` の現行比較版。森／洞窟、3段階、4枚の戦術評価カード、前衛撃破後の敵後衛逃走、主の身代わり敗北を維持します。

## 操作

- フィールドを押し続ける：敵前衛へ接近。
- 指を離す：敵前衛から離脱。何も触れていない間も離脱します。
- フィールドを素早くスワイプ：画面上のスワイプ方向へ回避。28px以上、開始から650ms未満。1回の接触につき1回だけ発動。
- 右下：斬撃／突き／強打を選び、攻撃ボタンで攻防を確定。別の指でフィールドを押しながら操作できます。
- PC：W/Sで接近／離脱、A/Dで旋回、Shift＋移動で回避、1/2/3で技、Jで攻撃。キーを離すと自動離脱に戻ります。

スワイプはカメラの投影から地面の方向へ変換します。敵との相対方向で上下左右の意味が逆転することはありません。設定・一時停止・画面切替・入力キャンセル・画面外への移動で押下状態を解除します。攻防演出中は移動も後衛も飛翔物も停止します。

## 後衛の追従

主人公と敵前衛だけが直接戦闘します。攻撃対象は敵前衛固定で、ターゲット切替はありません。

主は主人公の後ろ、敵後衛は敵前衛の後ろへ追従します。「後ろ」は、敵側の前衛から自分側の前衛へ向かう方向で決めます。基準距離は3.2、追従速度は6.8／秒、微小な位置差は0.12以内で停止します。回避で離れた際は追加速度で追いつきます。前衛が戦闘領域の端まで退いた場合、後衛はその外側の余白を使い、前衛に重なりません。

追従中も援護の周期は変えません。後衛は近接攻撃・前衛との衝突・通常の被攻撃対象には参加しません。

敵後衛の射撃は1.10秒の予兆開始時に主人公の位置を記録します。後衛自身は移動できますが、予告地点は変えず、その地点に向けて発射します。弾は追尾しません。射撃と敵前衛の警戒支援を交互に行い、警戒支援は待機／防御の状態を0.35秒延長するだけです。

## 画面と設定

戦闘中は主人公／敵前衛のHP、右下の攻撃操作、設定ボタン、短い操作案内を表示します。主と敵後衛の名札は短くし、敵後衛の射撃予兆だけを必要なときに表示します。

設定画面に、序盤／中盤／終盤、音、一時停止、環境鑑賞、森／洞窟、環境演出と攻撃演出の強度、操作説明をまとめました。数値調整と動作検証は「詳細調整・動作検証」に収納しています。射程ガイドは初期状態でOFFです。

設定を開くと戦闘・攻防カードの両方を停止し、閉じると元の状態に戻ります。段階変更は選んだ段階で再戦します。

## 3段階と勝敗

| | 序盤 | 中盤 | 終盤 |
| --- | ---: | ---: | ---: |
| 主人公HP | 70 | 100 | 145 |
| 斬撃／突き／強打 | 7 / 10 / 20 | 10 / 15 / 30 | 15 / 23 / 45 |
| 主の表示倍率 | 2 | 1 | 0.62 |
| 主の技 | 王の剣 | 魔法弾 | 弱い魔法弾 |
| 主の威力 | 48 | 13 | 2 |

敵前衛HP120、敵後衛HP75、敵後衛弾の威力8、敵AIと攻撃周期は全段階で共通。敵前衛HP0で弾と剣を消去し、敵後衛が0.90秒で逃走して勝利します。

主人公への致命傷は近接・後衛弾・カード反撃の共通入口で検知します。主人公HPを減らさずに主が庇い、0.18秒で死亡、0.85秒で敗北。序盤は転移、中盤以降は0.10秒の疾駆演出です。主の生存、10倍ダメージ、反撃はありません。

## 検証と残課題

`node tests/forest-action-frontline/logic.mjs`、`balance.mjs`、`browser.cjs`。詳細は `VALIDATION.md`。

自動離脱と後衛追従で援護が届きやすくなりました。固定操作モデルでは、終盤も無操作の自動離脱だけで長時間後に勝てるケースがあります。今回の変更は操作・追従・UIに限定し、敵の強さや援護威力は調整していません。iPhone実機Safari、実機FPS／発熱、人間による操作感は未検証です。
