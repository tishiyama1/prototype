# Forest Action Diorama — 忘れられた森の古道

通常3D版を複製して制作した、独立した景観比較版です。ピクセル版の描画コードは使用していません。

- 試遊：https://tishiyama1.github.io/prototype/forest-action-diorama/
- 通常3D版：https://tishiyama1.github.io/prototype/forest-action/
- ピクセル版：https://tishiyama1.github.io/prototype/forest-action-pixel/
- 画像比較：`comparison.html`

## 景観

横切る古道、まばらに埋まった石畳、奥左の崩れた石垣、奥右の欠けた石碑を構図の軸にしました。中央の土は低コントラストに保ち、草・苔・根・岩は周縁のまとまりへ集めています。楕円の円盤や境界線は描画せず、連続した地面と画面端の巨木で森を繋ぎます。

俯角43°、初期ズーム1.23倍、奥寄りの注視点。プレイヤーと敵の中点へ滑らかに追従し、離れた場合は両者が画面へ収まるよう引きます。方位は固定し、移動やスワイプの計算にカメラ値を使いません。通常版のカメラは53°／1倍です。

羊皮紙のカードUI・HP・操作ボタンは通常解像度のまま。カード演出のデザイン・時間・判定は変更していません。3Dも通常解像度、アンチエイリアスあり、DPR上限1.5です。

## 操作と比較

- WASD：敵へ接近／離脱／円弧移動。Shift＋WASD：高速移動。
- 1/2/3：斬撃／突き／強打を選択。J：攻撃指示。
- iPhone横画面相当：左スティック、右の技選択と攻撃。操作UI以外のフィールドをスワイプすると高速回避。
- カード演出中：タップ／Spaceで短縮。通常・高速・詳細モードは「調整」から選択。
- 「森を眺める」「静止画」：戦闘時間・AI・環境の動きを止める。「戦闘へ」で開始／再開。
- 「調整」：影、遠景フォグ、風・木漏れ日・浮遊粒子を切替可能。「初期設定に戻す」は描画設定も復元。

## 保護した仕様

戦闘・カード・入力の13モジュールを通常版からそのまま複製。技性能、敵AI、HP、ダメージ、自動踏み込み、カード評価、結果、演出時間、記録、リトライ、楕円11.5×7.2、両者の初期位置は維持しています。`config.js`の差はカメラ初期俯角・ズームのみ。

キャラクターは既存の寸法・関節・アニメーションを保ち、色を調整。関節に属する静的な部品だけを1メッシュへ統合し、28姿勢の世界寸法の同一性を検査しています。

## 実装

- `js/forest.js`：連続した地面、共有形状とInstancedMeshによる森・遺構、自然光・フォグ・環境の揺れ。
- `js/surface.js`：軽量な土・落ち葉・苔・樹皮・石材のCanvasTexture。外部素材のダウンロード不要。
- `js/model-batch.js`：可動関節を保持する描画用メッシュ統合。
- `js/camera.js`：構図と画面内収まり。戦闘座標を変更しない。
- `js/main.js`：静止画モードと描画比較設定、読み取り専用検査情報。

three.js **0.180.0**を既存と同じCDN/import mapから読み込みます。HTML/CSS/ES Modulesのみで、ビルド・npmインストール不要。Pagesの既存main/root配信方式を維持しています。

## 検証

`VALIDATION.md`に実測結果と未検証項目を記録。`DESIGN.md`に構図設計と調整理由を記録しています。

```
node tests/forest-action-diorama/logic.mjs
node tests/forest-action-diorama/regression.mjs
```

ブラウザ検査は`browser.cjs`（戦闘・タッチ29項目）、`visual.cjs`（3版起動・構図・遮蔽・姿勢・描画時間）です。実行環境にPlaywright/Chromiumが必要ですが、ゲームの配信には不要です。`FOREST_QA_URL`／`FOREST_VISUAL_BASE`で公開環境を検査できます。
