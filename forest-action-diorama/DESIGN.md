# 忘れられた森の古道 — 実装前の構図設計

基準：通常3D版（forest-action）の戦闘とカード演出を複製。ピクセル版からはコードも素材も流用しない。戦闘面は高さ0、楕円11.5×7.2、移動制限と両者の初期座標を維持する。

| 項目 | 初期設計 |
|---|---|
| カメラ | Orthographic、俯角43°、ズーム1.23。方位を固定し、両者の中点へ緩やかに追従。離れた場合は両者を収めるよう引く |
| キャラクター | 世界のモデル寸法は維持。現行の約1.5倍の画面サイズが目安。iPhone横画面で立った身体約40px、PCで約70pxを目標とし、実画面で測定する |
| 古道 | X軸を横切りながらZ≈−0.26Xへ緩く曲がる。土と草地は自然な幅の変化で繋ぐ。楕円の円盤・縁取りを描画しない |
| 中央 | 土色の低コントラスト地面。低く埋まった石と小量の葉のみ。敵の姿勢と剣を読みやすくする |
| 石垣 | 奥左、X−10.5〜−5.5／Z−4.8〜−7.6。崩れた壁の断片と苔。戦闘範囲には置かない |
| 石碑 | 奥右、X6.8／Z−7.3。欠けた頂部と浅い刻印、控えめな蔦。説明文・読める物語テキストはなし |
| 前景 | X±16付近の幹・大きな根、低木、岩で画面端を縁取る。中央手前に高い木を置かない |
| 中景 | 少数の主木、古道、壁、石碑、苔むした石。密度を空間ごとに変える |
| 遠景 | Z−13〜−32に奥ほど低コントラストの木々。距離フォグで層を作る。右奥の道に抜けを残す |
| 光 | 左奥からの自然光。土と人物周辺は明るく、植生の内側は冷たい緑。柔らかい1024pxの影1灯 |
| 色 | 苔 #70876b、葉 #456e58〜#7c9a69、木 #665646、土 #877c60、石 #85897c、遠景 #7b978a、光 #ffe7bf |
| 動き | 葉と草の小さな揺れ、16点以下の浮遊粒子。人物の予備動作より目立たせない |
| 描画 | 通常解像度＋AA、DPR上限1.5。形状・色・配置で表現し、色数制限や低解像度化をしない |

最初に地面、主木、石垣、石碑、カメラだけで構図を確認し、その後に根・草・小石・マテリアルを追加する。カメラ以外のゲーム設定、移動・敵AI・判定・カード演出は同一性テストで保護する。

ブロック配置の実画面では最初の46°／1.48倍で遺構が画面外へ出たため、43°／1.23倍、奥寄りの注視点へ修正しました。視認性だけでなく景観が残る構図を優先します。

詳細確認で道幅と樹冠の高さを再調整。奥へ3.2単位寄せた注視点により石碑・壁・若木が画面上部へ入り、43°／1.23倍を最終初期値としました。キャラクターの世界寸法は一切変えていません。
